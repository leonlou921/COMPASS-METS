# Training

## Model order

The final primary models are ResEncM and ResEncXL. The focal-Tversky FT donor
is a direct dependency of the final fusion chain and must be initialized from
the matching ResEncM fold. The small-lesion OS trainers are retained as key
ablations, not as final probability sources.

Run folds 0–4 unless an explicit fold list is supplied:

```bash
bash scripts/03_train_resencm_5fold.sh
bash scripts/04_train_resencxl_5fold.sh
bash scripts/05_train_small_lesion_ft_5fold.sh
```

For a smoke audit without launching training:

```bash
DRY_RUN=1 bash scripts/03_train_resencm_5fold.sh 0
DRY_RUN=1 bash scripts/04_train_resencxl_5fold.sh 0
DRY_RUN=1 bash scripts/05_train_small_lesion_ft_5fold.sh 0
```

Set `CONTINUE_TRAINING=1` only when resuming an existing fold. The authoritative
trainer settings live under `configs/trainers/`. Inference always uses
`checkpoint_best.pth`.

## OOF probabilities

After training, export validation probabilities from the best checkpoint:

```bash
bash scripts/06_generate_oof_probabilities.sh
```

Fold membership is the leakage boundary: every learned-gate row must be
generated by a model that did not train on that case.

## LCv1, LCv2, RGv3, and UTILITY_V4

Copy the templates under `configs/learned_gates/` to a private working
directory and fill in the real data/model paths. Then export:

```bash
export LCV1_CONFIG=/private/work/lcv1.json
export LCV2_CONFIG=/private/work/lcv2.json
export RGV3_COMPONENT_FEATURES=/private/work/component_features.parquet
export RGV3_CASE_PREDICTIONS=/private/work/lcv1_case_predictions.parquet
export RGV3_V2_PREDICTIONS=/private/work/lcv2_component_predictions.parquet
export RGV3_OUTPUT_ROOT=/private/work/rgv3
export UTILITY_FEATURES=/private/work/component_features.parquet
export UTILITY_V2_PREDICTIONS=/private/work/lcv2_component_predictions.parquet
export UTILITY_OUTPUT_ROOT=/private/work/utility_v4

SHARDS=1 bash scripts/07_train_learned_gates.sh
```

The ordered stages are:

1. LCv1 OOF case/component feature extraction and cross-fitting;
2. LCv2 OOF component scoring and calibration;
3. region-separated RGv3 cross-fitting;
4. UTILITY_V4 existence and geometry-safety training.

The final inference script consumes the final LCv1, LCv2, RGv3-ET, existence,
and geometry model files explicitly. No learned binary is committed.
